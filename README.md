# GSRP CAD - skrivbordsapp

Öppnar GSRP CAD (https://roblox-erlc.vercel.app) i ett eget fönster i stället för webbläsaren.
Samma CAD, samma funktioner - bara i en egen app.

## Ladda ner senaste versionen

Se [Releases](../../releases/latest) till höger.

- **Windows:** ladda ner `.exe`, dubbelklicka, installera. Windows SmartScreen kan varna (filen är
  inte signerad) - klicka "Mer info" -> "Köra ändå".
- **Mac:** ladda ner `.dmg` (arm64 = Apple Silicon/M-chip, annars den utan arm64), dra appen till
  Program. Första gången: högerklicka appen -> Öppna (Gatekeeper kan annars blockera den).
